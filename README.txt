# Dr. Abhishek Ray — Free Academic Website

This folder is ready to publish with GitHub Pages.

## Publish for free with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a new **public** repository named:
   `yourusername.github.io`
   (replace `yourusername` with your GitHub username).
3. Upload everything in this folder:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `Abhishek_Ray_Resume.docx`
   - `assets/profile.jpg`
4. Open the repository's **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. After GitHub publishes it, your website will be available at:
   `https://yourusername.github.io/`

The website uses no paid hosting. The Google Fonts import is optional; if you want the site to work with no external network resources at all, remove the `@import` line in `styles.css`.
